# Contributing to Our Collective Project

We welcome all contributions from individuals who want to build, refine, and support this project. Because this is a horizontal, anarchist space, we don't have gatekeepers. We collaborate through mutual aid, shared trust, and voluntary consensus.

## How to Get Involved

### 1. Finding Something to Work On
* **Check the board**: Look through the open issues or discussions to see what needs attention.
* **Propose changes**: If you see a problem or have an idea, feel free to open a new issue or starter discussion to share your thoughts with the collective.

### 2. Proposing Changes
* **Fork and branch**: Fork the repository and create your feature branch.
* **Keep it clean**: Write clear commit messages that explain *why* the change was made.
* **Open a pull request**: Submit your code or documentation changes back to the main repository for review.

### 3. Review and Consensus
* **Peer review**: No single person approves code. We review each other's work asynchronously.
* **Restorative feedback**: Keep feedback constructive, focusing on the work and our shared standards.
* **Consensus merge**: Once a pull request has received positive feedback/reviews from the active participants and no major objections are raised, any active collaborator can merge it.

## Documentation and Translation
Contributions aren't just code! We heavily value:
* **Improving documentation**: Making the project easier for others to understand and use.
* **Translations**: Helping localize the project so it is accessible across different regions and languages.
* **Design & feedback**: Testing the project and reporting bugs or usability issues.
